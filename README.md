# VMware Tools & Scripts

Repositorio de scripts y herramientas para automatizar tareas relacionadas con **VMware**.

La idea es simple: juntar en un solo lugar scripts que resuelvan tareas reales de administración, operación y mantenimiento de infraestructura VMware.


## ¿Qué contiene este repositorio?

El repositorio irá incorporando herramientas para tareas como:

- Administración de máquinas virtuales.
- Respaldos y restauración de VMDK.
- Compresión y optimización de discos virtuales.
- Automatización de tareas repetitivas.
- Migraciones y operaciones sobre máquinas virtuales.
- Mantenimiento de infraestructura VMware.
- Utilidades para trabajar con archivos y discos virtuales.

## Scripts

Los scripts se irán agregando a medida que sean necesarios y probados en escenarios reales.

Cada herramienta debería incluir su propia documentación, requisitos y ejemplos de uso.

## Filosofía

La idea de este repositorio no es reinventar VMware ni crear una plataforma de 800 componentes para ejecutar un `tar`.

Son **scripts simples, configurables y orientados a resolver problemas concretos**.

Preferentemente:

- Linux.
- Shell/Bash.
- Herramientas estándar cuando sea posible.
- Configuración clara.
- Salida comprensible.
- Nada de dependencias innecesarias.
- Y, sobre todo, que funcionen.


## Requisitos

Los requisitos dependen de cada script.

Cada herramienta deberá documentar sus dependencias y versiones necesarias en su propia documentación.
